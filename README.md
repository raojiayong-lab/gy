# 贵阳幼儿师范高等专科学校 · 公众号图文排版工具（公文版）

单文件、纯前端、零依赖的网页工具：把微信公众号图文粘进来，自动提取图片、按公文格式排版，再一键复制到公众号或导出 Word。

**在线使用：** https://raojiayong-lab.github.io/gypec-layout-tool/

## 功能

- **粘贴即用**：直接从微信文章复制正文+图片，粘进大窗即可（自动识别懒加载地址，破解微信图片防盗链）
- **图片自动提取**：较大的图自动进右侧小窗，可 **复制 / 下载 / 拖动到正文任意位置 / 一键设为 800×600 或 650×433**
- **图片过滤尺寸可调**：默认过滤小于 90px 的图，可随时改数字（0 = 不过滤），只隐藏不删除，调小立刻回来
- **公文正文默认值**：仿宋_GB2312 · 三号(16pt) · 固定值 28 磅行距 · 首行缩进 2 字符
- **快捷样式**：选中文字点一下套用 标题 / 正文 / 加粗 / 居中 / 右对齐 / 去缩进
- **一键复制**：带完整格式（字体/字号/行距/缩进/对齐），粘到 Word 或公众号编辑器格式不丢
- **导出 Word**：联网生成 .docx，离线自动降级为 .doc（同样保留公文格式）
- **校标与入口**：左上角为学校校徽；右侧可直达「新闻管理」与「学校官网」

## 部署

仓库根目录只需一个 `index.html`（自包含，校标已内嵌 base64），GitHub Pages 从 `main` 分支根目录发布。

```
index.html    # 唯一需要部署的文件
README.md     # 本说明
```

任何静态托管都可以：Vercel / Netlify（拖拽即出链接）、对象存储（COS/OSS 开静态网站）、自有服务器（丢到网站根目录）。

## 隐私

不含任何密钥/密码；所有解析与排版都在浏览器本地完成，不向任何服务器上传内容。
